# Portfólio - Rodrigo Costa

Portfólio pessoal desenvolvido durante meus estudos de Desenvolvimento Front-end.

## 📌 Status

Versão 1.0 concluída.

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
- Git e GitHub

## 🎯 Objetivo

Criar um portfólio para apresentar meus projetos, estudos e habilidades em Desenvolvimento e Qualidade de Software.

## ⚙️ Funcionalidades

- Navegação entre as seções do portfólio
- Modo claro e modo escuro
- Armazenamento da preferência de tema com LocalStorage
- Layout responsivo para diferentes tamanhos de tela
- Apresentação dos projetos de Desenvolvimento e QA
- Página dedicada para apresentação do projeto de testes de software
- Links para GitHub e LinkedIn

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei conceitos de HTML, CSS e JavaScript, incluindo organização semântica da página, estilização, responsividade e manipulação do DOM.

Também implementei persistência de dados no navegador utilizando LocalStorage e utilizei Git e GitHub para controle de versão do projeto.
